# Problem Statement

Retail businesses generate large volumes of sales data every day.

However, raw data alone cannot support business decision-making.

The objective of this project was to convert raw transactional data into meaningful business insights using modern data analytics techniques.

---

# Dataset

The project uses the Supermarket Sales Dataset.

It contains:

- 1000 records
- 17 features
- Sales information
- Customer details
- Product categories
- Branches
- Cities
- Payment methods

---

# Task 1

The first task focused on:

- Data Cleaning
- Data Preprocessing
- Exploratory Data Analysis

Python libraries including Pandas, NumPy, Matplotlib and Seaborn were used.

Several visualizations were created to understand sales patterns and customer behavior.

---

# Task 2

Task 2 focused on SQL.

Business queries were written to extract valuable insights including:

- Branch performance
- Product sales
- Customer analysis
- Revenue analysis

Python was integrated with SQL for automated querying.

# Task 3

Interactive dashboards were developed using Microsoft Power BI.

The dashboard contains:

- KPI Cards
- Sales by Branch
- Product Analysis
- Customer Ratings
- Interactive Filters

These dashboards enable quick business decision-making.

---

# Task 4

Advanced analytics included:

- Statistical Analysis
- Time Series Forecasting
- Customer Segmentation
- Random Forest Regression
- Feature Importance Analysis

These techniques helped predict future trends and identify important business factors.
