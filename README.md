## 📌 Overview

This repository contains the final deliverables for my **45-Day Data Analytics Internship** at **ApexPlanet Software Pvt. Ltd.**

The project demonstrates an end-to-end data analytics workflow using the **Supermarket Sales Dataset**, covering data preprocessing, SQL analytics, dashboard development, statistical analysis, machine learning, reporting, and deployment.

---

# 🎯 Objectives

- Perform data cleaning and preprocessing
- Conduct Exploratory Data Analysis (EDA)
- Extract business insights using SQL
- Build interactive Power BI dashboards
- Perform statistical analysis
- Forecast future sales using Time Series models
- Segment customers using Machine Learning
- Develop predictive models
- Produce a professional executive report
