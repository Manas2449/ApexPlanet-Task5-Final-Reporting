# Problem Statement

Retail businesses generate large volumes of transactional data every day. However, raw data alone does not provide meaningful insights for decision-making. Organizations require efficient data analytics techniques to clean, analyze, visualize, and model data in order to identify business trends, customer behavior, sales performance, and future opportunities.

The objective of this internship project was to transform a raw supermarket sales dataset into actionable business insights using modern Data Analytics, Business Intelligence, Statistical Analysis, and Machine Learning techniques.

## Task 4 – Advanced Analytics

### Statistical Analysis

- Performed descriptive statistical analysis.
- Conducted inferential statistical tests.
- Evaluated confidence intervals and hypothesis testing.

### Time Series Analysis

- Converted transactional data into time series format.
- Applied Moving Average and Exponential Smoothing.
- Built an ARIMA forecasting model for sales prediction.

### Customer Segmentation

- Applied K-Means clustering.
- Determined the optimal number of clusters using the Elbow Method and Silhouette Score.
- Profiled customer segments based on purchasing behavior.

### Predictive Modeling

Three predictive models were developed and evaluated.

| Model | Performance |
|--------|-------------|
| Linear Regression | R² = **0.905** |
| Logistic Regression | Accuracy = **92.0%** |
| Decision Tree | Accuracy = **96.5%** |

The Decision Tree model achieved the highest classification performance among the implemented models.
